Papercut - Convert Source Code to PDF
======================================

Thank you for downloading Papercut!

INSTALLATION INSTRUCTIONS
-------------------------

1. Drag "Papercut.app" to your Applications folder (or the Applications shortcut
   in this window).

2. (Optional) Double-click "Install CLI Tool" to add the 'papercut' command to
   your Terminal PATH. This will allow you to run 'papercut' from any directory.

   You will be prompted for your administrator password.


USING PAPERCUT
--------------

Command Line:
  If you installed the CLI tool, simply open Terminal and run:

    papercut input.py -o output.pdf

  Otherwise, you can run:

    /Applications/Papercut.app/Contents/MacOS/papercut input.py -o output.pdf

GUI:
  Currently, Papercut is a command-line tool only. Double-clicking the app
  will not open a graphical interface.


GETTING HELP
------------

For usage instructions and examples:
  papercut --help

For documentation:
  https://github.com/yourusername/papercut


UNINSTALLING
------------

To uninstall Papercut:

1. Delete Papercut.app from your Applications folder
2. If you installed the CLI tool, remove the symlink:

     sudo rm /usr/local/bin/papercut
